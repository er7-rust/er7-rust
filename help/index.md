# Help

Operational checklists at the workspace level — things that are true of
the repository as a whole, not of one crate. Each crate has its own
`help/` for crate-specific checklists (`er7/help/`, `er7-redact/help/`,
`serde-er7/help/`).

| Page | What it covers |
| ---- | -------------- |
| [outreach](outreach/index.md) | the prerequisites this repository must meet before any promotion, checked against the tree as it stands today |

For the reasoning behind the workspace-level rules, see
[`spec/`](../spec/index.md), and for agent guidance on the workspace as a
whole, [`AGENTS.md`](../AGENTS.md).
