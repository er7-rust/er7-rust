# Onboarding

Where to start if you are new to these crates, to HL7® v2, or to both. Each
page is short and links onward. The crates' own `docs/` directories and
specifications go deeper.

| Page | Read it when |
| ---- | ------------ |
| [Your first message in 5 minutes](getting-started/index.md) | you want to parse, query, edit, and write a message now |
| [Which crate do I need?](which-crate/index.md) | you are choosing between `er7`, `er7-redact`, and `serde-er7` |
| [HL7 v2 for Rust developers](hl7-v2-for-rust-developers/index.md) | you know Rust but not how an HL7 v2 message maps onto Rust types |
| [Glossary](glossary/index.md) | a term, a path, or a type name is unfamiliar |

Then:

- the [`er7` tutorial](../er7/docs/usage/index.md), for everything the
  first page only touches;
- the [`er7` FAQ](../er7/docs/faq/index.md), which covers repeating fields,
  custom delimiters, and the explicit null;
- the site's [format page](https://er7-rust.github.io/format/), for ER7
  itself: delimiters, escapes, batches, and the wire.
